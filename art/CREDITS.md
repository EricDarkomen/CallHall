# Character art credits

The character sprites in this game are pixel art from the **Liberated Pixel Cup**
community. Each sheet in `art/sprites/` is built from one source project, pinned
at one commit:

- `art/sprites/world.png` — [ElizaWy/LPC](https://github.com/ElizaWy/LPC), commit `f07f7f5892e67c932c68f70bb04472f2c64e46bc`
- `art/sprites/revised.png` — [ElizaWy/LPC](https://github.com/ElizaWy/LPC), commit `f07f7f5892e67c932c68f70bb04472f2c64e46bc`

**The original artwork has been modified**: layers were composited into single
characters, recoloured using the LPC palette definitions, cropped to the walking
and standing frames, and packed into a sheet per source project.

This art is **not** covered by the game's CC BY-NC-ND 4.0 licence — see `LICENSE`, part 2.

Attribution does not imply endorsement by any contributor, by OpenGameArt.org,
